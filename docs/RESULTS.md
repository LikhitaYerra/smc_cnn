## Scenario-by-Scenario Interpretation

### Normal

CNN-adaptive SMC matches classical SMC exactly — both use the same parameter set when the environment is classified as normal.

### Noise

Chattering reduced by **35.53%**, but RMSE increases by **10.98%** and final error by **15.02%**. This reflects a deliberate trade-off: smoother control at the cost of tracking precision under sensor noise.

### Disturbance

RMSE improves by **2.22%** and final tracking error by **36.96%**. The adaptive controller recovers faster after an external push.

### Slip

RMSE improves by **1.57%** and final error by **32.27%**, indicating better recovery when wheel slip reduces effective velocity.

### Combined

Chattering reduced by **27.67%** with a slight final-error improvement (+2.16%), but RMSE worsens by 2.00%. The combined condition remains the most challenging scenario.

---

## Conclusions

The CNN-adaptive SMC pipeline demonstrates:

- **Reduced chattering** in noisy and combined conditions
- **Improved recovery** under disturbance and slip (final error)
- **Scenario-aware parameter switching** based on CNN classification

Trade-offs exist between tracking precision and control smoothness. The PPO RL agent (see `src/rl/`) provides an alternative that learns continuous gain adaptation rather than discrete lookup-table switching.
